# 방탈출 게임 에셋 제작 가이드 (등장인물·장소/건물)

> 목적: 장면 HTML에 그림 코드를 직접 넣지 않고, **같은 폴더에 저장된 개별 HTML 파일**(예: `민우.html`, `A_패루.html`)을 불러와 장면을 조립하기 위한 규격입니다. 이 규격을 지켜야 여러 에셋을 섞어도 크기·정렬이 일관되고, 스크롤바나 잘림 없이 깔끔하게 삽입됩니다. 생성형 AI에게 에셋을 그리게 할 때 아래 규격과 프롬프트 템플릿을 그대로 사용하세요.

---

## 1. 공통 원칙 (인물·장소 공통)

- **파일 하나 = 개체 하나.** 각 파일은 그 자체로 독립적으로 표시/삽입될 수 있어야 합니다.
- **배경은 투명.** 무대·화면 전체를 덮는 불투명 배경(하늘/바닥 사각형 등)을 깔지 않습니다. 장면 위에 얹었을 때 배경이 비쳐야 합니다.
- **외부 의존 최소화.** 그림은 순수 HTML/CSS/SVG 도형으로만 그리고, 외부 이미지·아이콘·스크립트 링크는 쓰지 않습니다. CSS는 파일 안 `<style>`에 내장합니다.
- **크기 규격 고정 + 스크롤 금지.** 각 개체는 정해진 표시 크기를 가지며, 삽입 시 스크롤바가 생기지 않도록 콘텐츠가 상자 밖으로 넘치지 않게 그립니다.

---

## 2. 등장인물 파일 규격

캐릭터는 여러 명을 한 장면에 겹쳐 배치하고 위치를 자유롭게 잡아야 하므로 **"조각(fragment)"** 형태로 만듭니다.

- **문서가 아니라 조각.** `<!DOCTYPE>`/`<html>`/`<body>` 없이 **`<div>`로 시작**합니다.
- **최상위 래퍼:** `<div class="영문이름-component" style="display:inline-block; overflow:visible !important;">` … `</div>`
- **표준 무대 크기 260×320px 고정.** 내부에 `.접두사-stage { position:relative; width:260px; height:320px; margin:0 auto; overflow:visible; }`. 이 크기는 **절대 개별로 바꾸지 않습니다** (모든 캐릭터가 같은 규격이라 자동으로 키가 맞음).
- **고유 접두사.** 모든 클래스명과 `@keyframes` 이름 앞에 2~3글자 고유 접두사를 붙입니다. (예: 민우=`kmw-`, 서연=`ksy-`) → 여러 캐릭터를 한 장면에 넣어도 CSS가 충돌하지 않습니다.
- **발 기준선 정렬.** 머리는 무대 위쪽(대략 `top:50px`), 몸통 하단이 무대 아래쪽(대략 290px)에 오도록 그려, 캐릭터마다 **발끝 높이(baseline)가 같게** 합니다. 그래야 여러 명을 세웠을 때 키가 나란합니다.
- **애니메이션은 transform으로.** 은은한 숨쉬기(예: `translateY`, `scale`) 정도만 넣고, 잘리지 않도록 무대는 `overflow:visible`.
- **그리는 방법:** `position:absolute` + 도형(`div`, `border-radius`, `gradient`, `border`)으로 표현합니다.
- **마주보기가 필요하면** 삽입하는 장면 쪽에서 `transform: scaleX(-1)`로 좌우 반전합니다(파일 자체는 정면 기준으로 제작).

---

## 3. 장소/건물 파일 규격

건물·장소는 배경 요소로 크게 쓰이고 크기를 다양하게 조절해야 하므로 **"완성된 문서"** 형태로 만들되, **크기 조절에 강한 SVG viewBox 방식**을 권장합니다.

- **완성 문서.** `<!DOCTYPE html>`부터 `</html>`까지 하나의 온전한 HTML 문서.
- **body 기본값:** `body { margin:0; padding:0; background:transparent; overflow:hidden; }`
- **★그림은 `<svg viewBox="0 0 W H">`로 그린다.★** viewBox 방식은 iframe 크기만 정하면 자동으로 확대/축소되어 삽입이 쉽습니다. `svg { display:block; width:100%; height:auto; }`
  - (고정 픽셀 `div` 레이아웃도 가능하지만, 축소할 때 `transform:scale`을 따로 걸어야 하고 잘못하면 잘려서 깨집니다. 되도록 SVG를 쓰세요.)
- **viewBox를 콘텐츠에 딱 맞게.** 그림 상하좌우의 **빈 여백을 최소화**합니다. 여백이 많으면 장면에서 실제 그림이 작게 보입니다.
- **배경 투명.** 하늘/바닥처럼 화면 전체를 덮는 불투명 사각형을 넣지 않습니다.
- **파일명 규칙:** `알파벳_이름.html` (예: `A_패루.html`). 앞 알파벳은 지도상의 순서 표시용입니다.
- **원본 크기 표기.** 코드 상단에 표시 크기를 주석으로 남깁니다. 예: `<!-- 원본 크기: 900x650 -->` (장면에 삽입할 때 이 값이 필요합니다.)

---

## 4. 크기 일관성 규칙

- **인물:** 모두 260×320을 공유하므로 자동으로 크기가 맞습니다. 개별로 크기를 재지정하지 마세요.
- **건물:** 가로세로 비율이 제각각이라 완전히 같게는 못 맞춥니다. 대신 **공통 박스에 비율 유지(contain-fit)** 로 맞춰 편차를 줄입니다. 원본 크기 W×H, 목표 박스 예 140×130이면 `scale = min(140/W, 130/H)`. (미니맵/지도용 기준입니다.)
- **장면 배경으로 쓸 때는** 더 크게 — 건물 표시 높이가 무대 높이(약 600px)의 55~75% 정도가 되게 하고, 건물이 여러 개면 같은 목표 높이를 공유해 크기 편차를 줄입니다.

---

## 5. 삽입(로딩) 방식 요약

- **인물(조각):** `fetch()`로 파일을 읽어 지정한 컨테이너의 `innerHTML`에 삽입하고, `position:absolute`로 위치를 잡습니다. 감싸는 wrapper는 `overflow:visible`, `overflow:auto/scroll` 금지. (로컬 `file://`에서 fetch가 막히면 투명 `iframe`으로 대체하되 260×320 규격은 동일하게 유지.)
- **건물(SVG 문서):** 투명 `iframe`으로 삽입. viewBox 방식이면 iframe의 width/height만 정하면 그림이 자동으로 맞춰집니다. (`scrolling="no"`, `border:0`.)
- **건물(고정 픽셀 문서):** iframe의 width/height에 **원본 W·H를 그대로** 넣고 `transform:scale(s)`로 축소, 감싸는 div를 `(W*s)×(H*s)`로 맞춤. iframe을 작은 값으로 직접 바꾸면 그림이 넘쳐 잘립니다.

## 6. AI에게 그대로 붙여넣을 프롬프트 템플릿

### (A) 등장인물 제작용

```
너는 웹 방탈출 게임용 캐릭터를 순수 HTML/CSS 도형으로 그리는 일러스트레이터야.
아래 규격을 엄격히 지켜 '○○○' 캐릭터 한 명을 그려줘.

[출력 형식]
- <!DOCTYPE>/<html>/<head>/<body> 없이, 아래처럼 '조각(fragment)' 하나만 출력한다.
  <div class="영문이름-component" style="display:inline-block; overflow:visible !important;"> ... </div>
- 이 div 안에 <style>(내장 CSS)과 마크업을 모두 포함한다. 외부 이미지/폰트/스크립트 링크 금지.

[규격]
- 무대: .접두사-stage { position:relative; width:260px; height:320px; margin:0 auto; overflow:visible; }
  → 크기 260×320은 고정. 절대 다른 값으로 바꾸지 말 것.
- 모든 클래스명과 @keyframes 앞에 2~3글자 '고유 접두사'를 붙여 다른 캐릭터와 이름이 겹치지 않게 한다. (예: mnw-)
- 배경 투명(무대에 배경색/배경 사각형 넣지 말 것).
- 인물은 정면. 머리는 무대 위쪽(top ≈ 50px), 몸통 하단이 무대 아래(≈ 290px)에 오도록 그려 '발 기준선'을 맞춘다.
- 은은한 숨쉬기 애니메이션(transform: translateY/scale) 정도만, overflow는 visible.
- position:absolute + div/border-radius/gradient/border 도형으로만 그린다.

[캐릭터 설명]
○○○: (성별·의상·머리·표정 등 외형을 구체적으로 묘사)
```

### (B) 장소/건물 제작용

```
너는 웹 방탈출 게임용 '장소/건물'을 순수 HTML/SVG로 그리는 일러스트레이터야.
아래 규격을 지켜 '○○○'을(를) 그려줘.

[출력 형식]
- <!DOCTYPE html>부터 </html>까지 '완성된 단일 HTML 문서'로 출력.
- body { margin:0; padding:0; background:transparent; overflow:hidden; }
- 외부 이미지/폰트/스크립트 링크 없이 코드로만 그린다.

[규격]
- ★그림은 <svg viewBox="0 0 W H"> 로 그린다.★ (크기 조절에 강한 방식)
  svg { display:block; width:100%; height:auto; }
- viewBox는 그림 내용에 '딱 맞게' 잡아 상하좌우 빈 여백을 최소화한다. (여백이 많으면 장면에서 작게 보임)
- 배경 투명 — 하늘/바닥처럼 화면 전체를 덮는 불투명 배경을 깔지 말 것.
- 완성 후, 이 그림의 원본 표시 크기(viewBox의 W×H)를 코드 맨 위 주석으로 적어줘.
  예: <!-- 원본 크기: 900x650 -->

[건물 설명]
○○○: (형태·색·특징적 요소를 구체적으로 묘사)
```

## 7. 제출 전 체크리스트

**등장인물**
- [ ] `<div class="...-component">` 조각으로 시작(문서 태그 없음)
- [ ] `.접두사-stage`가 260×320, 크기 재지정 없음
- [ ] 모든 클래스/@keyframes에 고유 접두사
- [ ] 배경 투명, 발 기준선(하단) 정렬
- [ ] overflow:visible, 스크롤 없음

**장소/건물**
- [ ] 완성된 HTML 문서(`<!DOCTYPE html>`~`</html>`)
- [ ] `<svg viewBox>` 방식, 여백 최소
- [ ] 배경 투명, body `margin:0; overflow:hidden`
- [ ] 원본 크기 주석 표기(`<!-- 원본 크기: WxH -->`)
- [ ] 파일명 `알파벳_이름.html`
