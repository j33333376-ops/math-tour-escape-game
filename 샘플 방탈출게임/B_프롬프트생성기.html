🧩 차이나타운 체험학습앱 장면 프롬프트 생성기

제작할 페이지를 입력하세요. 파일명·이전/다음 페이지를 설정한 뒤 버튼을 누르면 완성된 프롬프트가 생성됩니다.
디자인 스타일: 근대 개항기

※ 쉼표(,)로 구분해 여러 개 입력할 수 있어요. 입력 시 띄어쓰기는 자동 제거됩니다. 건물은 'A_' 같은 접두사 없이 이름만(예: 패루) 입력하세요. 여기 적은 인물·건물이 같은 폴더의 HTML 파일로 불러와집니다. 에셋 생성기로 새로 만들어 이름.html로 저장한 인물·건물도 그 이름을 그대로 입력하면 불러옵니다.

※ '다음 페이지'를 비워두면 마지막 페이지로 간주되어, '다음' 버튼 대신 End 버튼이 나타나도록 프롬프트가 작성됩니다.
