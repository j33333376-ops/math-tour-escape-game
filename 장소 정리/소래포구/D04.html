활동 2 · 모든 순간의 신호를 일반항으로 해독하기

매 순간의 계단 수를 한 번에 찾을 수 있도록, 발자국의 규칙을 식으로 바꿔봅시다.

핵심 신호: an = a₁ + (n−1)d를 전개하면, 매분 변하는 양인 공차 d가 n의 계수가 됩니다.
an = 50 + (n−1)(−10)
(n−1)(−10) = (공차 × n) + 10
an = n + 60

공차가 −10일 때, n 앞에 들어갈 계수를 부호까지 정확히 입력하세요.

an = 50 + (n−1)(−10) = 50 − 10n + 10 = −10n + 60 공차 d = −10이 일반항에서 n의 계수가 됩니다. 즉, 등차수열의 일반항에서 n의 계수는 수열이 한 번 진행할 때마다 변하는 양을 나타냅니다.
💡 먼저 수열의 빈칸을 모두 채워보세요.
