색을 바꾸고 싶다면

모든 면은 var(--이름, 기본값) 형태로 칠해져 있습니다. 파일을 그대로 쓰면 원본 색이 나오고, 바깥에서 변수만 덮어쓰면 형태는 그대로 둔 채 색만 갈아입힐 수 있습니다.

<style>
  /* 읽음을 민트 톤으로 */
  .mint { --read-skin:#8FD6C4; --read-cheek:#F0805A; }
</style>
<div class="mint"> ... 읽음 SVG 붙여넣기 ... </div>
